# ZZveenus legal pages for GitHub Pages

This folder is a static copy of the current Privacy Policy and Terms of Use. It is prepared for GitHub Pages and does not change the live bot website.

To publish it, create a public GitHub repository and upload the contents of this folder to the repository root. In the repository, open Settings > Pages and choose Deploy from a branch, then select the main branch and the root folder.

After GitHub Pages finishes publishing, the links will be:

- `https://OWNER.github.io/REPOSITORY/privacy.html`
- `https://OWNER.github.io/REPOSITORY/terms.html`

Replace `OWNER` and `REPOSITORY` with the actual GitHub account and repository. Enter the exact published URLs in the Discord Developer Portal and save the application settings.
